description: Prepare or repair a project's Playwright BDD setup and validate a small starter suite, without modernizing the application.
---

Read the [modernize skill](../../skills/modernize/SKILL.md) from the loaded plugin
and follow its shared rules and package-root resolution.

Treat the accompanying text and conversation as a setup-only request. No migration
target is required. Discover and reuse existing infrastructure, tests, package
manager, service lifecycle and saved setup before adding anything.

Follow [E2E setup](../../skills/modernize/references/e2e-setup.md) to prepare or
repair the original test copy, selected fixtures and a small runnable BDD starter
suite. Keep the active application unchanged. Ask only for essential access, missing scope or human-owned
behavior and real-versus-mocked dependency decisions; do not require a setup form.
Do not upgrade application dependencies merely to fit the test tooling.

Record actual checks, limits and the next action in the existing setup, test
preparation and workflow records, and refresh the report at the saved checkpoint.
Distinguish scaffold readiness, stack/fixture checks and executed starter tests
from sufficient preservation coverage and a qualifying measured baseline.

Stop after the requested setup or repair and its bounded validation. Do not create
a modernization candidate, transform application code, configure CI, commit, push
or open a pull request unless separately requested. A later modernization request
must still satisfy the existing coverage review and fresh baseline requirements.
