# User guide

Code Modernisation brings the Claude code-modernization workflow to GitHub
Copilot chat. Describe the outcome; the plugin investigates behavior, establishes
tests, implements a separate candidate and checks the result. An HTML report
shows saved progress and helps you continue later.

Start with [installation](getting-started.md) and the
[small review example](examples.md). You can then assess your own application or
request a bounded change directly.
